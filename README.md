📌 Overview

This project focuses on predicting the sales of products in Big Mart stores using Machine Learning.
The goal is to help businesses understand how different factors like product type, store details, and pricing affect sales, and use this information to make better decisions.

🎯 Problem Statement

Big Mart has sales data for different products across multiple stores.
The challenge is to predict the sales of each product based on available features such as item weight, item type, store size, and location.

🧠 Solution Approach

Performed data cleaning and preprocessing

Handled missing values and categorical features

Conducted Exploratory Data Analysis (EDA) to understand data patterns

Applied feature engineering to improve model performance

Trained and evaluated machine learning models to predict sales

🛠️ Technologies & Tools Used

Python

Pandas, NumPy – Data handling

Matplotlib, Seaborn – Data visualization

Scikit-learn – Machine Learning models

Jupyter Notebook

📊 Machine Learning Techniques

Regression-based models

Model evaluation using appropriate metrics

Comparison of model performance

🚀 How to Run the Project

📈 Results

The trained model successfully predicts product sales with reasonable accuracy and provides insights into which factors influence sales the most.
